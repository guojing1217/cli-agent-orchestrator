# Environment Variables

CAO behavior can be configured via environment variables.

| Variable | Description | Default |
|----------|-------------|---------|
| `CAO_CONFIG_PATH` | Path to configuration file | `~/.config/cao/config.yaml` |
| `CAO_DEFAULT_PROVIDER` | Default AI provider | `claude-code` |
| `CAO_WEB_UI_PORT` | Web UI server port | `8080` |
| `CAO_MCP_SERVER_PORT` | MCP server port | `3000` |
| `CAO_SESSION_TIMEOUT` | Session timeout in seconds | `3600` |
| `CAO_LOG_LEVEL` | Logging level | `INFO` |
